适用范围
本包为已有汉化安装的增量修复，基于本项目使用的 Steam Windows 汉化 debug 版本制作。不含游戏本体，不是干净英文版的一键完整汉化；其他版本兼容性尚未验证。

安装
1. 保存进度并完全退出游戏。
2. 备份游戏目录 BackboneStories/Content/Paks/ 中与本包同名的三个附加 Pak 文件，以及你的存档。不要删除或覆盖原游戏主 Pak。
3. 将本包中的 BackboneStories 文件夹合并至游戏根目录。只替换三个同名附加补丁。
4. 重新启动游戏，检查菜单、对白与互动标签。

回退
完全退出游戏后，恢复第2步备份的同名文件。若安装前没有某个同名附加包，将此次新增的对应附加包移出 Paks 目录即可。不要删除原游戏主 Pak。

当前内容
对白和互动资源修复、中文换行、姓名与菜单动态文字补全；修复范围来自多个批次，存在重叠。没有删除对白。
